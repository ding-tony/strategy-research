61 saved paper-strategy runs from 19 reviewed reports, snapshot October 11, 2026. Includes historical backtests and paper replays; no real holdings, personal ledgers, credentials or live-lab files. JSON extracts live in `reports/data/`. No raw market-data caches are distributed.

The comparator works offline: download `index.html` and open it in a browser. Only saved tested combinations are displayed; changing one rule may select the closest available tested run. Compare all rules and warnings before drawing conclusions.

Results exclude fees, spread, slippage, FX and taxes. Historical-universe and data-coverage limitations remain; these in-sample results are not forecasts or investment advice. The metrics are auditable against included report text, but this repository does not contain the engine or all inputs needed to rerun backtests.

GitHub Pages publishes the committed static snapshot from `main`. Updating research requires a reviewed new export; it is not connected to any portfolio API.
